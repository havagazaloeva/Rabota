# VD Games

Collection of mini-games for learning Python.

## Games

- **VD-even** - Guess if number is even
- **VD-calc** - Calculate arithmetic expressions
- **VD-gcd** - Find greatest common divisor
- **VD-progression** - Find missing number in progression
- **VD-prime** - Guess if number is prime

## Installation

```bash
make install
make build
make package-install
```

## Usage

```bash
VD-progression
VD-prime
```
